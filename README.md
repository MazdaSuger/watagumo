# アトリエわたぐも 業務管理ツール

小規模服飾ブランド「アトリエわたぐも」向けの、ローカルで動く業務管理ミニツールです。

## 使い方

`index.html` をダブルクリックするだけで、ブラウザ（Chrome / Safari など）で開けます。
インターネット接続やインストールは不要です。スマートフォンでも利用できます。

## 現在できること

### 原価計算（`index.html`）

商品の情報を入力すると、自動で次の項目を計算します。

- **入力項目**：商品名 / 販売価格 / 生地単価 / 使用ｍ数 / 副資材費 / 梱包費 / 送料 / 販売手数料率 / 制作時間
- **計算結果**：材料費合計 / 販売手数料 / 利益 / 利益率 / 時給換算
- **保存**：商品ごとのデータをブラウザ内（localStorage）に保存
- **CSV書き出し**：保存した商品を Excel などで開けるCSVファイルに出力

> 利益がマイナス（赤字）になると、利益と利益率が赤色で表示されます。

#### 計算の内容

- 材料費合計 ＝ 生地単価 × 使用ｍ数 ＋ 副資材費 ＋ 梱包費 ＋ 送料
- 販売手数料 ＝ 販売価格 × 販売手数料率 ÷ 100
- 利益 ＝ 販売価格 − 材料費合計 − 販売手数料
- 利益率 ＝ 利益 ÷ 販売価格 × 100
- 時給換算 ＝ 利益 ÷ 制作時間（分）× 60

## データの保存場所について

保存したデータは、使用しているブラウザの中（localStorage）に記録されます。
別の端末・別のブラウザには引き継がれません。記録を残したい場合は CSV で書き出してください。
