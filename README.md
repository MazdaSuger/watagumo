# アトリエわたぐも 業務管理ツール

小規模服飾ブランド「アトリエわたぐも」向けの、ローカルで動く業務管理ミニツールです。

## 使い方

`index.html`（原価計算）または `order.html`（受注管理）をダブルクリックするだけで、
ブラウザ（Chrome / Safari など）で開けます。画面上部のメニューで2つのツールを行き来できます。
インターネット接続やインストールは不要で、外部への通信は一切行いません。スマートフォンでも利用できます。

## 現在できること

### 原価計算（`index.html`）

商品の情報を入力すると、自動で次の項目を計算します。

- **入力項目**：商品名 / 販売価格 / 生地単価 / 使用ｍ数 / 副資材費 / 梱包費 / 送料 / 販売手数料率 / 制作時間
- **計算結果**：材料費合計 / 販売手数料 / 利益 / 利益率 / 時給換算
- **保存**：商品ごとのデータをブラウザ内（localStorage）に保存
- **CSV書き出し**：保存した商品を Excel などで開けるCSVファイルに出力

> 利益がマイナス（赤字）になると、利益と利益率が赤色で表示されます。

#### 計算の内容

- 材料費合計 ＝ 生地単価 × 使用ｍ数 ＋ 副資材費 ＋ 梱包費 ＋ 送料
- 販売手数料 ＝ 販売価格 × 販売手数料率 ÷ 100
- 利益 ＝ 販売価格 − 材料費合計 − 販売手数料
- 利益率 ＝ 利益 ÷ 販売価格 × 100
- 時給換算 ＝ 利益 ÷ 制作時間（分）× 60

### 受注管理（`order.html`）

注文の情報を登録し、進行状況を管理できます。

- **管理項目**：注文番号 / 注文日 / 顧客名 / 商品名 / サイズ / 生地 / 価格 / 支払い状況 / 制作ステータス / 発送予定日 / 発送日 / 追跡番号 / 備考
- **制作ステータス**：受注 → 入金確認 → 生地準備 → 裁断 → 縫製 → 仕上げ → 梱包 → 発送済み → 完了
- **並び順**：発送予定日が近い注文を上に表示（完了した注文は下にまとめます）
- **発送が近い注文**：発送予定まで3日以内・本日・超過の注文は色付きの目印を表示
- **検索・絞り込み**：顧客名・商品名・注文番号での検索、ステータスでの絞り込み
- **編集・削除**：登録済みの注文を後から修正・削除
- **CSV書き出し**：注文一覧をCSVファイルに出力
- 個人情報を扱うため、データは端末内（localStorage）にのみ保存し、外部通信は行いません

## データの保存場所について

保存したデータは、使用しているブラウザの中（localStorage）に記録されます。
別の端末・別のブラウザには引き継がれません。記録を残したい場合は CSV で書き出してください。
